# ShoppyGlobe E-Commerce Application

## Project Description

ShoppyGlobe is a React-based e-commerce application developed using Vite.

## Features

- Product Listing
- Product Details
- Shopping Cart
- Quantity Management
- Remove Product
- Checkout
- Search using Redux
- React Router
- Redux Toolkit
- Lazy Loading
- Responsive UI

## Technologies Used

- React
- Vite
- Redux Toolkit
- React Router DOM
- CSS

## Installation

```bash
npm install
npm run dev
```
